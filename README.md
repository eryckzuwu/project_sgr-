# Sistema de Gestão - World Tennis

Sistema web desenvolvido em HTML, CSS e JavaScript para auxiliar no gerenciamento das operações de uma loja World Tennis.

## Funcionalidades

- **Dashboard:** visão geral, relatórios e indicadores.
- **Estoque:** consulta de modelos, controle de quantidades e movimentações.
- **Pedidos:** cadastro e acompanhamento de pedidos.
- **Entrada de mercadorias:** registro de notas fiscais e produtos recebidos.
- **Vendas:** registro de vendas, trocas, pagamentos e descontos.
- **Funcionários:** cadastro e gerenciamento de funcionários e escalas.
- **Lojas:** cadastro de lojas e consulta de estoques.
- **Transferências:** movimentação de mercadorias entre lojas.
- **Controle de acesso:** liberação, devolução e registro de defeitos.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `Backup_4.html` em um navegador.
3. Faça login com as credenciais cadastradas no sistema.
